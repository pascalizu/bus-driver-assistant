# Bus Driver Assistant: Multi-Agent Vision AI with Voice Alerts

An intelligent real-time safety system for buses that monitors driver fatigue, tracks passengers, detects objects, delivers voice announcements, and supports natural language queries.

## Overview

The Bus Driver Assistant is a multimodal AI application designed to improve safety and operational efficiency in buses. It uses computer vision to detect driver fatigue and monitor passengers, provides automatic and manual voice announcements for safety compliance, logs all events, and allows users to query historical data using natural language powered by Gemini 3 Flash Preview.

This project demonstrates a complete multi-agent system with real-time vision, voice output, memory management, and intelligent querying — built for Ready Tensor Module 2.

## Target Audience

- Public and private bus fleet operators
- School bus companies
- Transportation safety researchers
- AI/ML developers interested in multi-agent systems and computer vision
- Ready Tensor reviewers and certification participants

## Prerequisites

- Python 3.10 or higher
- Webcam (for real-time monitoring)
- Speakers or headphones (for voice announcements)
- Internet connection (for Gemini 3 Flash Preview)
- Basic knowledge of Python and computer vision

**Recommended Hardware:**
- Windows 10/11 machine with at least 8GB RAM (16GB+ recommended for smoother performance)
